# jwbae-plugins

Claude Code plugin marketplace by jwbae.

## Installation

```
/plugin marketplace add hohre12/jwbae-plugins
```

## Available Plugins

| Plugin | Description | Install |
|--------|-------------|---------|
| **[immunity](https://github.com/hohre12/immunity)** | The immune system for AI-generated code. Adversarial review, self-verifying contracts, change impact tracking, production readiness analysis. | `/plugin install immunity` |
| **[agent-harmony](https://github.com/hohre12/agent-harmony)** | One prompt to production. Multi-pass quality assurance for autonomous AI development. | `/plugin install agent-harmony` |
| **[feed](https://github.com/hohre12/feed)** | SNS content generator & publisher. Interview-driven workflow for Threads, X, Reddit, and Dev.to. | `/plugin install feed` |
| **[agent-orchestra](https://github.com/hohre12/jwbae-plugins/tree/main/agent-orchestra)** | Observable multi-agent orchestration. An orchestrator leads a native Agent Team (project-tailored workers + a standing reviewer + an adversarial critic) you watch live in cmux panes, with an objective gate that re-runs your tests/lint/build. Scaffolds the standard `.claude/`, briefs Redmine issues, works over Remote Control. | `/plugin install agent-orchestra@jwbae-plugins` |
